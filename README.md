# Talking avatar


A ThreeJS-powered virtual human being that will sell people your inventory, A fully conversational system that understands/analyses emotions and responds accordingly.

[ta.webm](https://user-images.githubusercontent.com/1557195/209548068-9b55b5a6-c4dd-4f7c-979f-87fefa0fcb74.webm)




## Run
```
$ yarn install
$ yarn start
```

## Backend
You'll also need https://github.com/bornfree/talking_avatar_backend for the text to speech conversion.
